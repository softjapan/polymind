Features

1つのアプリで、使いたいAIをすべて。

設定画面からプロバイダーをいつでも切り替え。会話の中身は端末からAIプロバイダーへ直接送信され、開発者のサーバーは存在しません。

OpenAI
Google Gemini
Anthropic Claude
Ollama（ローカルLLM）

リアルタイム・ストリーミング

各プロバイダーのChatモデルからトークン単位で応答を描画。生成中はいつでも即座に停止できます。

Markdown・コードハイライト

見出し・リスト・コードブロックを美しくレンダリング。ライト/ダークモード双方に最適化した配色です。

画像入力（Vision）

写真を添付してAIに質問できます。図表の読み取りや画像に関する相談にも対応。

画像生成

/image コマンドでOpenAIの画像生成APIを呼び出し、チャット内にそのまま表示・保存できます。

会話履歴・検索

SQLiteでローカル保存。サイドドロワーから会話の一覧・検索・リネーム・削除が行えます。

プライバシー重視の設計

APIキーは端末のセキュアストレージにのみ保存。開発者は会話内容やAPIキーを一切収集しません。

自前のサーバーはありません

PolyMind はあなたの端末と、選んだAIプロバイダーの間を直接つなぐクライアントです。APIキー・会話内容の収集は一切行わず、広告・解析SDKも含まれていません。詳しくはプライバシーポリシーをご覧ください。
